## Day 4: Python Operators

## Goal

The goal of Day 4 is to understand how Python operators are used to perform operations on variables and values. Operators are essential for performing calculations, making comparisons, checking conditions, and working with data in Python programs.

## Topics Covered

### Arithmetic Operators

Arithmetic operators are used to perform mathematical operations on numbers.

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `//` Floor Division
* `%` Modulus
* `**` Exponentiation

### Comparison Operators

Comparison operators are used to compare two values. The result of a comparison is either `True` or `False`.

* `==` Equal to
* `!=` Not equal to
* `>` Greater than
* `<` Less than
* `>=` Greater than or equal to
* `<=` Less than or equal to

### Assignment Operators

Assignment operators are used to assign and update values stored in variables.

* `=`
* `+=`
* `-=`
* `*=`
* `/=`
* `//=`
* `%=`
* `**=`

### Logical Operators

Logical operators are used to combine conditional expressions.

* `and`
* `or`
* `not`

### Membership Operators

Membership operators are used to check whether a value exists within a sequence such as a string, list, tuple, or set.

* `in`
* `not in`

### Identity Operators

Identity operators are used to check whether two variables refer to the same object in memory.

* `is`
* `is not`

## Learning Outcome

By completing Day 4, I learned how to use different types of operators in Python and understood how expressions are evaluated. I also practiced performing arithmetic calculations, comparing values, combining conditions, checking membership, and understanding the difference between equality and object identity.
